# Universal Intent Decoding Checklist

Use this checklist whenever evaluating a user prompt across any domain—including teaching/education, office administration, creative writing, visual artifacts, or engineering.

---

## 1. Domain & Artifact Identification
- [ ] **Domain Classification**:
  - [ ] **Education & Teaching** (lesson plans, rubrics, classroom activities, student worksheets, curriculum)
  - [ ] **Office & Administration** (forms, spreadsheets, processes, meeting minutes, policy documents)
  - [ ] **Creative & Communication** (articles, marketing, story outlines, newsletters, video scripts)
  - [ ] **Technical & Engineering** (code, architecture, database schemas, scripts)
- [ ] **Material Format**: Is the input an image, whiteboard photo, scanned form, markdown draft, spreadsheet, or code snippet?
- [ ] **Audience Level**: Who is the end-consumer? (e.g., 4th-grade elementary students, company executives, direct reports, external clients).

---

## 2. Context Archaeology
- [ ] **Marginal & Embedded Clues**:
  - Did a teacher write time allocations (e.g., *"10 min intro"*, *"exit ticket before bell"*)?
  - Did an office manager leave problem notes (e.g., *"people keep forgetting due dates"* )?
  - Did an author use specific tone markers or bolded phrases?
  - Did a developer leave `TODO:` or `FIXME:` comments?
- [ ] **Existing Constraints**: What rules, templates, or standard operating procedures are already established?

---

## 3. The "Job to Be Done" (Decoding Intent)
- [ ] **The Real-World Goal**:
  - For a teacher: Is the goal an engaging, frictionless 45-minute lesson for tomorrow morning?
  - For an office worker: Is the goal eliminating lost inventory and clarifying accountability?
  - For a writer: Is the goal persuading a leadership committee to approve a budget?
  - For a developer: Is the goal preventing an out-of-memory crash without alien dependencies?
- [ ] **Unspoken Companion Assets**: What related assets does the user naturally need to make the solution complete?
  - Lesson plan -> needs student worksheet + teacher answer key.
  - Policy form -> needs instructions + return verification section.
  - Strategy memo -> needs executive summary + timeline.

---

## 4. Outside-the-Box Thinking
- [ ] **Practical Differentiation**: Did we provide accommodations or options for different skill levels or scenarios?
- [ ] **Friction Reduction**: Did we remove unnecessary steps or ambiguity?
- [ ] **Next-Step Anticipation**: Will the user need to follow up tomorrow, and did we make that follow-up effortless?

---

## 5. Vision Alignment & Voice
- [ ] **Tone Fidelity**: Does the output sound like an authentic educator, executive, or domain expert?
- [ ] **Format Consistency**: Did we maintain familiar formatting (tables, bullet points, checklists, or code style)?
- [ ] **Empathetic Alignment**: Did we briefly confirm our understanding of the user's vision before delivering the solution?
